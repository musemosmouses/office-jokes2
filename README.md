## The entry

> I replied-all to say please stop replying-all, and now there are forty-seven emails about my email.

99 characters, one line. The attempt to stop the reply-all storm becomes the storm itself — the punch lands on the last few words.

## Run

```sh
node main.ts
```

Writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (or `./out` when unset). Deterministic, no network, no dependencies.
